# 뱃지 대비 이슈 (미해결 — 별도 작업으로 분리)

싱글페이지 UI 개편(틴트 섹션 도입) 과정에서 측정한 색상 대비 문제 기록. 색상
체계(포인트 컬러 팔레트) 자체를 건드려야 하는 사안이라 UI 리팩토링 커밋에
섞지 않고 별도 작업으로 분리해둔다.

## 처리 완료

뱃지가 배경(특히 tint 섹션 `#e1f4ec`)에 묻혀 보이는 문제는 **모든 뱃지에 얇은
흰 테두리(`ring-1 ring-white`)를 추가**하는 방식으로 해결했다 (섹션 variant와
무관하게 전 섹션 동일 적용). 대상: `PublicationsExplorer`의 journal/conference/
patent 뱃지, `NewsExplorer`의 Announcement/Updates 뱃지.

## 미해결 — 뱃지 위 텍스트 가독성 대비

`text-ewha-green-900`(#00462a)를 아래 뱃지 배경 위에 얹었을 때의 WCAG 대비비.
**틴트 도입 이전부터, 흰 배경에서도 이미 존재하던 이슈**다.

| 뱃지 | 배경색 | 텍스트 대비비 | WCAG AA(4.5:1, 일반 텍스트) |
|---|---|---|---|
| `ewha-yellow-green` | #bcc924 | 6.03 | 통과 |
| `ewha-blue` | #45a2bc | 3.74 | **미달** |
| `ewha-mint` | #36aebc | 4.16 | **미달** |
| `ewha-coral` | #f27367 | 3.89 | **미달** |

## 참고: 뱃지 배경 자체의 분리 대비 (배경과 뱃지가 얼마나 도드라지는지)

| 뱃지 | vs 흰 배경(#fff) | vs 틴트(#e1f4ec) |
|---|---|---|
| `ewha-yellow-green` | 1.82 | 1.59 |
| `ewha-blue` | 2.94 | 2.57 |
| `ewha-mint` | 2.65 | 2.31 |
| `ewha-coral` | 2.47 | 2.47 |

## 해결 선택지 (아직 미적용)

- (b) 틴트 섹션에서만 뱃지를 흰 pill 위에 얹고 뱃지 색은 점/보더로 축소
- (c) 포인트 컬러 자체를 더 진한 톤으로 교체 (브랜드 팔레트 의미 체계 변경 필요 — 콘텐츠팀 협의 필요)
- (d) 뱃지 텍스트를 `text-white`로 변경 — 단 `ewha-yellow-green`은 밝은 배경이라 흰 텍스트와도 대비가 낮아지므로 이 뱃지만 예외 처리 필요

측정 스크립트: WCAG 상대휘도 공식 기반 Node 스크립트로 계산 (`(L1+0.05)/(L2+0.05)`).
